## 1. 文档目的

本文档记录第二工位各测量算法的 **工程接入状态** 与 **调用方式**。

接入原则：

- **动态库（DLL）方式引入**，不将算法源码编入 IPC 工程。
- 算法仓独立编译 → 打包 SDK → 工位仓 `third_party/` 引用 → `modules/` 薄封装 → 主流程调用。
- 采集（Mech-Eye / 海康）与算法解耦；算法只吃内存中的点云或约定格式的文件。

主流程（PLC 触发、阈值判定、HMI 展示）的联调节奏见 [flow_control 架构说明](./guides/flow_control架构说明.md)；本文档侧重 **算法层是否就绪、如何调用**。

## 3. 通用接入模式（后续算法参照）

后续算法建议复用与 **焊缝测量** 相同的模式：

```text
算法 VS 工程
  └─ 新增 DynamicLibrary 工程 + 稳定 C API 头文件
  └─ scripts/package_sdk_to_ipc.ps1  →  third_party/<name>/

IPC_Station2
  ├─ cmake/<Name>Sdk.cmake          # IMPORTED 目标 + POST_BUILD 部署
  ├─ modules/<name>/                # Qt/C++ 薄封装（Service / Types）
  ├─ app/CMakeLists.txt             # scan_tracking_deploy_*_runtime
  └─ flow_control / 其它模块        # 业务调用点（可后接）
```

**SDK 目录约定**（以焊缝为例）：

```text
third_party/weld_measure/
├── include/weld_measure_c_api.h
├── lib/Release/WeldMeasure.lib
├── lib/Debug/WeldMeasure.lib          # 可选；缺失时 Debug 复用 Release
├── bin/Release/WeldMeasure.dll
├── bin/Release/onnxruntime.dll
├── models/pointnet_weld_seam_V7.3_good.onnx
└── weld_measurement.ini               # 参考配置（运行时非必须）
```

**运行时部署**（相对 `scan-tracking.exe`）：

| 文件 | 路径 |
|------|------|
| 算法 DLL | 与 exe 同目录 |
| ONNX Runtime（焊缝） | 与 exe 同目录 |
| PCL 运行时（厚度） | 与 exe 同目录 |
| 焊缝模型 | `models/weld_measure/*.onnx` |
| 厚度参考配置 | `config/thickness_measure/thickness_config.json` |

## 4. 焊缝截面测量（已接入）

### 4.1 功能说明

单截面焊缝几何测量，流程：

1. PointNet ONNX 识别左右焊趾  
2. 错边量、余高、母材夹角、棱角度  
3. 左右咬边深度（单截面）

> **不包含**：多截面咬边**长度**统计（见第 7 节「咬边长度测量」）。

### 4.4 依赖

| 依赖 | 说明 |
|------|------|

| Eigen 3.x | **仅 DLL 内部**使用；工位工程不依赖 |
| PCL | **已去除**；点云为轻量 POD 结构 |

工具链：算法 DLL 与 IPC 均使用 **MSVC v142（14.29）x64**。

### 4.5 输入 / 输出

**输入**

- 类型：`float` 数组，**交错** `x,y,z,x,y,z,...`
- 语义：**单个焊缝截面**点云（单位 mm）
- 非有限值（NaN/Inf）在 DLL 内自动跳过

**输出**（`WeldSectionMeasurement` / `wm_section_result`）

| 字段 | 含义 |
|------|------|
| `mismatchMm` | 错边量 (mm) |
| `reinforcementMm` | 余高 (mm) |
| `angularityMm` | 棱角度 (mm) |
| `includedAngleRad` | 母材延长线夹角 (rad) |
| `leftUndercutMm` / `rightUndercutMm` | 左右咬边深度 (mm) |
| `maxUndercutMm` | 截面最大咬边深度 (mm) |
| `leftToe*` / `rightToe*` | 左右焊趾坐标 |
| `valid` | 测量是否有效 |

### 4.6 调用方式

#### 方式 A：C++ 封装（推荐）

```cpp
#include "scan_tracking/weld_measure/weld_measure_service.h"

using scan_tracking::weld_measure::WeldMeasureService;
using scan_tracking::weld_measure::WeldSectionMeasurement;
using scan_tracking::weld_measure::WeldMeasureError;

WeldMeasureService service;
WeldMeasureError err;
if (!service.initialize(/* modelPath */ QString(), &err)) {
    // err.message
    return;
}

WeldSectionMeasurement result;
if (!service.measureSection(xyz, pointCount, &result, &err)) {
    // err.statusCode, err.message
    return;
}
// result.mismatchMm, result.reinforcementMm, ...
```

- 默认模型路径：`<applicationDir>/models/weld_measure/pointnet_weld_seam_V7.3_good.onnx`
- 同一 `WeldMeasureService` 实例内调用已串行化（DLL 内部 mutex）
- 使用前需 `initialize()`；进程退出或切换模型前可 `shutdown()`

#### 方式 B：C API（跨模块 / 工具）

头文件：`third_party/weld_measure/include/weld_measure_c_api.h`

```c
wm_onnx_config onnx;
wm_onnx_config_default(&onnx);
onnx.model_path = "D:/path/to/model.onnx";

wm_context* ctx = NULL;
wm_create(&onnx, &ctx);

wm_options opt;
wm_options_default(&opt);

wm_section_result result;
char msg[512];
wm_measure_section(ctx, xyz, point_count, &opt, &result, msg, sizeof(msg));

wm_destroy(ctx);
```

```powershell
# 1. 编译 DLL

# 2. 打包到 IPC third_party
```

然后在 IPC 仓重新编译 `scan-tracking` 即可。

### 4.9 已知限制

1. **输入必须是截面点云**；Mech-Eye 整段扫描云需后续增加切片或离线截面文件。  
2. **咬边长度**不在本 DLL 内，需接入「咬边长度测量」算法。  
3. Debug 配置若未单独打包 Debug DLL，CMake 会回退使用 Release 版。  
4. ONNX 模型路径建议使用绝对路径或相对 exe 的部署路径，避免依赖进程 cwd。

## 5. 厚度测量（已接入，主流程未调用）

> **源码**：`第二工位测量源码/厚度测量`  
> **状态**：✅ SDK + 薄封装已接入；⏸ `flow_control` / 主流程 **尚未调用**

### 5.1 功能说明

- **输入**：多对连续帧点云（内表面一帧 + 外表面一帧为一对）  
- **输出**：筒体焊缝附近厚度；多对时可输出 **平均厚度**

流程概要：内外扫描点云预处理 → 分别与内外模板 ICP → 在模板坐标系下按特征点求厚度（默认 `nearest_between_surfaces`）。

### 5.2 接入状态

| 项 | 状态 |
|----|------|
| 算法 DLL `ThicknessMeasure.dll` | ✅ 已编译（v142 / x64 / `/MD`，Release） |
| C API `thickness_measure_c_api.h` | ✅ |
| SDK 打包至 `third_party/thickness_measure` | ✅（当前仅 Release；Debug 回退 Release） |
| CMake `ThicknessMeasureSdk.cmake` | ✅ |
| 封装模块 `scan_tracking_thickness_measure` | ✅ |
| 链接进 `scan-tracking` + 运行时拷贝 | ✅ |
| 主流程 PLC/HMI 调用 | ⏸ **未接**（按计划先接入后调用） |
| 模板点云现场部署路径 | ⏸ 待后续（`initializeFromJson` 依赖 JSON 内模板路径） |

### 5.3 工程路径

| 用途 | 路径 |
|------|------|
| 算法源码 / DLL 工程 | `D:\work\LY\第二工位测量源码\厚度测量` |
| DLL 工程 | `ThicknessMeasureDll.vcxproj` |
| 打包脚本 | `厚度测量/scripts/package_sdk_to_ipc.ps1` |
| IPC SDK | `third_party/thickness_measure/` |
| CMake | `cmake/ThicknessMeasureSdk.cmake` |
| 封装头文件 | `modules/thickness_measure/include/scan_tracking/thickness_measure/` |
| 封装实现 | `modules/thickness_measure/src/thickness_measure_service.cpp` |

### 5.4 依赖

| 依赖 | 说明 |
|------|------|
| PCL 1.12（vc142） | **仅 DLL 内部**；运行时随 SDK 部署 `pcl_*.dll` |
| Eigen / Boost / FLANN | **仅 DLL 内部**；工位工程不依赖 |
| 轻量 PCD 加载 | DLL 内 `SimplePcdIo`，不依赖 `pcl_io`/VTK/OpenNI |

工具链：算法 DLL 与 IPC 均使用 **MSVC v142（14.29）x64**。IPC Debug 工程可链接 **Release** 算法库（与焊缝同策略）。

### 5.5 输入 / 输出

**输入**

- 扫描点云：`float` 交错 `x,y,z,...`（单位 mm）；非有限值在 DLL 内跳过  
- 一对 = 内表面扫描 + 外表面扫描  
- 模板：内存点云，或由 `thickness_config.json` 中的 PCD 路径加载

**输出**

| 类型 | 主要字段 |
|------|----------|
| 单对 `ThicknessPairMeasurement` | `thicknessMm`、内外 ICP fitness、最近点等 |
| 多对平均 `ThicknessAverageMeasurement` | `thicknessMm`（成功对均值）、`successCount` |

### 5.6 调用方式（供后续主流程使用；当前未接线）

#### 方式 A：C++ 封装（推荐）

```cpp
#include "scan_tracking/thickness_measure/thickness_measure_service.h"

using scan_tracking::thickness_measure::ThicknessMeasureService;
using scan_tracking::thickness_measure::ThicknessPairMeasurement;
using scan_tracking::thickness_measure::ThicknessMeasureError;

ThicknessMeasureService service;
ThicknessMeasureError err;
if (!service.initializeFromJson(/* configPath */ QString(), &err)) {
    // 或 service.initialize(config, innerTpl, nInner, outerTpl, nOuter, &err);
    return;
}

ThicknessPairMeasurement result;
if (!service.measurePair(innerXyz, innerCount, outerXyz, outerCount, &result, &err)) {
    return;
}
// result.thicknessMm
```

- 默认配置路径：`<applicationDir>/config/thickness_measure/thickness_config.json`
- 同一实例内调用已串行化
- 多对平均：`measurePairsAverage(...)`

#### 方式 B：C API

头文件：`third_party/thickness_measure/include/thickness_measure_c_api.h`

```c
tm_context* ctx = NULL;
tm_create_from_json("D:/path/thickness_config.json", &ctx);

tm_pair_result result;
char msg[512];
tm_measure_pair(ctx, inner_xyz, inner_n, outer_xyz, outer_n, &result, msg, sizeof(msg));

tm_destroy(ctx);
```
